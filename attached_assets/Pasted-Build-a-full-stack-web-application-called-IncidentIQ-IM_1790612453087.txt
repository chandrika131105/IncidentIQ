Build a full-stack web application called "IncidentIQ".

IMPORTANT CONTEXT:
This application is for a hackathon where Hindsight by Vectorize is a mandatory technology. The project must demonstrate an AI agent that uses persistent memory to learn from previous software incidents and provide better responses to future incidents.

PROJECT IDEA:
IncidentIQ is an AI Incident Response Agent for software/DevOps teams.

The agent should:
1. Receive a production incident.
2. Recall relevant historical incidents from Hindsight.
3. Use the recalled memories together with the current incident to generate an analysis.
4. Recommend investigation steps and possible resolutions.
5. Store new incident knowledge/outcomes in Hindsight so future incidents can benefit from it.

CRITICAL REQUIREMENT:
Hindsight MUST be the actual persistent memory system.

Do NOT replace Hindsight with:
- FAISS
- Chroma
- Pinecone
- Weaviate
- another vector database
- SQLite as a substitute for memory
- an in-memory Python dictionary
- localStorage
- fake/mock memory

Use the current official Hindsight documentation and SDK:
https://hindsight.vectorize.io/
https://docs.hindsight.vectorize.io/
https://docs.dev.hindsight.vectorize.io/python-sdk/

Before implementing Hindsight, verify the CURRENT official API/SDK syntax from the documentation. Do not guess API method names.

CORE HINDSIGHT WORKFLOW:

When an incident is submitted:

1. Build a meaningful recall query from the incident.
2. Call Hindsight recall.
3. Retrieve relevant historical incidents.
4. Give the current incident + recalled memories to the LLM.
5. Generate a structured response.
6. Clearly show which memories were recalled.
7. Allow the incident outcome to be retained in Hindsight.

If no relevant memory is found, explicitly tell the user:
"No relevant historical incidents were found in memory."

Do not pretend that a memory was recalled when it was not.
